# Caso de Teste - TC-005: Consulta de encomendas

## 1. Identificação

* Identificação única: TC-005
* Nome do caso: Testes de consulta de encomendas
* Tipo de teste: Teste de cenário

## 2. Objetivo

Validar que o sistema apresenta corretamente as encomendas cadastradas e permite identificar as encomendas que ainda aguardam retirada.

## 3. Lista dos scripts de teste

* TST-007 Consulta de encomendas cadastradas
* TST-008 Consulta de encomendas pendentes

## 4. Casos de uso relacionados

* UC-004 Consultar encomendas

## 5. Critérios de validação

* O sistema deve apresentar as encomendas cadastradas.
* As informações exibidas devem corresponder aos registros existentes.
* A situação atual de cada encomenda deve ser apresentada corretamente.
* O sistema deve permitir identificar quais encomendas ainda aguardam retirada.

## 6. Observações

Este caso de teste contempla o fluxo principal da consulta de encomendas e o cenário de consulta das encomendas que ainda estão pendentes de retirada.
