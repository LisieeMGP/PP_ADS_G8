# GitHub Projects - Tarefas da Aula 3

Use as colunas abaixo no quadro:

- Backlog
- In Progress
- Done

## Tarefas prontas para colar no GitHub Projects

### 1. Configurar stack do projeto

Descrição: Criar a estrutura inicial do frontend Angular, da API NestJS e do banco PostgreSQL, além de configurar a execução com Docker Compose.

### 2. Implementar autenticação do sistema

Descrição: Criar o fluxo de login, autenticar usuários com JWT e proteger as rotas que exigem acesso autenticado.

### 3. Implementar cadastro de moradores

Descrição: Criar a funcionalidade de cadastro de moradores, com validação dos dados e persistência no banco.

### 4. Implementar consulta de moradores

Descrição: Exibir a lista de moradores cadastrados e permitir consulta das informações relevantes para uso no sistema.

### 5. Implementar registro de encomendas

Descrição: Criar a funcionalidade de registrar encomendas, validando morador, descrição e código de rastreio, e persistindo os dados no banco.

### 6. Implementar consulta de encomendas

Descrição: Listar as encomendas existentes, com filtro por morador, unidade, código de rastreio e status, para facilitar a visualização.

### 7. Implementar retirada de encomendas

Descrição: Permitir que uma encomenda seja marcada como retirada, atualizando o status, a data e o usuário responsável pela movimentação.

### 8. Configurar banco de dados e dados iniciais

Descrição: Criar o script de inicialização do PostgreSQL, definir as tabelas e inserir dados iniciais de usuários, moradores e encomendas para testes.

### 9. Validar funcionamento da API e regras de negócio

Descrição: Testar os fluxos principais da aplicação, confirmar que os dados são gravados e consultados corretamente e validar o comportamento sem erros.

### 10. Publicar a aplicação em produção

Descrição: Configurar o deploy no Render para frontend e backend, ajustar variáveis de ambiente e validar que a aplicação está acessível publicamente.

### 11. Validar a aplicação em ambiente publicado

Descrição: Testar login, cadastro de moradores, cadastro e consulta de encomendas, retirada e comportamento geral da aplicação em produção.

### 12. Criar guia do usuário

Descrição: Produzir um documento explicando como acessar a aplicação, fazer login e utilizar cada funcionalidade disponível.

### 13. Criar diagrama de implantação

Descrição: Elaborar um diagrama UML de implantação demonstrando os componentes de software, os dispositivos envolvidos e os links de comunicação da solução.

### 14. Registrar acompanhamento da iteração no quadro

Descrição: Registrar as tarefas planejadas, em andamento e concluídas durante a iteração, mantendo evidência de acompanhamento da entrega.

### 15. Preparar entrega final da Aula 3

Descrição: Confirmar a versão final entregue, registrar a tag no Git, documentar evidências e garantir que a entrega esteja alinhada ao gabarito da disciplina.
